This folder holds BizHawk 2.11.1, the emulator the stream bot runs in.

Download BizHawk-2.11.1-win-x64.zip from
https://github.com/TASEmulators/BizHawk/releases and extract its contents
into this folder, so that EmuHawk.exe sits right here next to this file.
Then double-click start.bat. Only BizHawk 2.11.1 is tested.
